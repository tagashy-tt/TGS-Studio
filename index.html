About

One developer.
Real products.

TGS Studio is a solo software and media development operation focused on creator tools and community infrastructure. Every project is designed, built, and maintained by Tagashy — a systems engineer and indie developer based online.

The work spans Discord bots, Chrome extensions, and web platforms, with a recurring focus on TikTok tooling, ffmpeg pipelines, and anime content communities.

TGS Studio isn't a large team — it's a commitment to shipping things that actually work, with real users and real deployments behind every project.
